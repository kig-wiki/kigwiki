tldr: makers that are not being used in the makers page exist here.

Theres no strict criterea of why a maker is here rather than listed.

Generally reasons tend to fall into:

- Infrequently open makers
  - Rins is made an exception to this purely as an example of what a top tier maker can look (and be
    priced) like.
- Makers no longer taking commissions or have retired.
- Makers of dubious quality.
- Makers difficult for westerners to commission.
  - There are so many amazing Chinese based makers however with many requiring proxy services, we
    are trying to avoid filling the entire list with only such makers. Future considerations will be
    taken regarding how to best handle this.

If theres a reason you think a maker should be moved to the main makers list, please make a pull
request or open an issue on github.
