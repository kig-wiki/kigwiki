# Kigurumi Mask Makers & Stores

This directory lists **Kigurumi Mask makers** so you can compare recent work. This isn't a definitive list of every single maker in the world, but is intended to be a list of makers that are active, easily commissionable, and have a strong presence in the Kigurumi community.

Use the **English Ordering** filter when you need to write the maker directly. Read [how to order a Kigurumi Mask](./commissioning-guide.md) first. New to the kigurumi? Start with [Kigurumi Mask basics](../Start/mask-basics.md). A full costume usually adds a [Hadatai](./hadatai.md).

:::info

Prices can fluctuate and vary greatly from mask to mask depending on the complexity of a commission, it's difficult to provide a single price estimate for makers, so we give general price ranges instead.

:::

Note: Location labels are provided as geographic references to help readers understand potential shipping and customs considerations.

### Maker Styles

Makers often develop various approaches to face shape, paint, eyes, and hair.  
We recommend checking out several recent commissions and seeing if any characters they've made line up similarly with the vision you have for yours.

Some makers are more stylized than others putting their own spin on characters, while some may be more faithful to the reference material.  
Typically most newer makers lean towards the latter, modelling the mask directly after your reference material.

### Ordering Tips

- Check whether commissions are open and how the maker accepts inquiries, some have sites, some prefer DMs, some prefer emails.
- Compare work similar to your character rather than relying on one portfolio image.
- Ask for the full price, expected start date, production window, and policies.
- Prepare references and measurements using the [Kigurumi Mask ordering guide](./commissioning-guide.md).
- Almost all makers have a social media presence of some kind, if you find a random shop or seller that doesn't, be wary and consider checking out [Kigurumi Mask seller red flags](./seller-red-flags.md). This is typically more common with random shops on Etsy, Ebay, or Aliexpress rather where they're just stealing photos off maker's social media accounts and presenting them as their store's inventory as "available product".
